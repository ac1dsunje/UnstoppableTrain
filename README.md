game for the jam - https://alashkz.itch.io/unstoppable-express

attempt to create first game from start to end. The idea was something like u resolve a trolley problem but people have random roles and traits
so you need to choose which line is better for you

Some events:
- epidemic - you need doctor for every sick passenger. if u dont have - they die..
- engine breakdown - just waste of time so you better have 1+ mechanics in your pack
- conflicts - psychoes have chance to start a conflict so its good to have some leaders that would try to stop this otherwise someone dies..
